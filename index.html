Step 2: Install the Mod (Easy as Pie!)

Download and extract the file, then run the application. Don’t worry — it’s much simpler than it sounds:

  1. Find the downloaded .zip file in your Downloads folder.
  2. Right-click it and choose “Extract All…”. Pick a safe location like your Desktop.
  3. Open the extracted folder. Inside, you’ll find a file called Winhttp.dll or BepInEx folder.
  4. Copy all the files from the extracted folder.
  5. Navigate to your game’s installation folder. In Steam, right-click on Chill with You → Manage → Browse local files.
  6. Paste the copied files into that folder. If asked to replace anything, click Yes.
  7. Done! Launch the game normally via Steam. The mod loads automatically.

Step 3: Add Your First Station

Once in-game, look for the radio or music icon. Click the right mouse button on it to open the mod’s custom menu. From there, choose “Add Station”, paste a direct streaming URL of your favorite radio station (e.g., https://example.com/radio/lofi.mp3), give it a name, and save. The tune will start playing instantly!

❓ Need a Hand?

🔊 No sound when switching stations?

Ensure your internet connection is stable. Also, double-check that your custom URL directly points to an audio stream (MP3, AAC, OGG, PLS formats work best). Some websites embed players instead of offering a direct stream link — if that happens, try right-clicking the player page and selecting “Copy audio address”.

🖥️ Game won’t start after installation?

Make sure you extracted the files correctly and inserted them into the game folder, not a subfolder. Steam’s “Browse local files” opens the exact folder needed. Double-check there’s no accidental nested Chill-With-You-Radio-Mod folder. If issues persist, verify game files via Steam properties and reapply the mod.
